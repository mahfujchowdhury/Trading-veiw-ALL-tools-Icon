## 🎯 Drawing Modifier Keys (Hold While Drawing)

> These are the keys that give you **precision drawings**.

| Hold | Effect |
|---|---|
| `Ctrl / Cmd` | **Magnet Mode (temporary)** — snaps drawing to the exact Open/High/Low/Close of the bar. If magnet is already ON, holding Ctrl turns it OFF temporarily. Also works while dragging an existing drawing's anchor point. |
| `Shift` | **Locks the angle** — trendlines/channels snap perfectly horizontal or at exact 45° angles. Fib keeps the second anchor level. |
| `Ctrl + Shift` together | **Pro combo** — snaps to exact OHLC price AND locks the angle horizontal/45°. Institutional-style precision. |
| `Shift` + Rectangle | Perfect square |
| `Shift` + Ellipse | Perfect circle |
| `Shift` + Drag a drawing point | Moves that point only horizontally/vertically (other anchor stays fixed) |
| `Shift` while placing Gann Box | Fixed increments |
| `Shift + Click` | Measure tool (distance, %, bars between two points) |

### Permanent Magnet Mode settings (magnet icon in left toolbar)
- **Weak magnet** — snaps only when close to a bar
- **Strong magnet** — snaps from any distance

## 💡 Pro Tips

1. **Top 10 to memorize first:** `/` (indicators), `Alt + A` (alert), `Alt + H` (horizontal line), `Alt + T` (trendline), `Alt + F` (fib), `Alt + W` (watchlist), `Alt + R` (reset chart), `,` (timeframe), `Ctrl + S` (save layout), `Ctrl` while drawing (snap to exact price).
2. **Custom hotkeys:** You can remap any shortcut in chart settings — they sync with your account across devices.
3. **Shortcuts not working?**
   - Click the chart once to give it focus (shortcuts differ when in watchlist/Pine Editor/screener).
   - Browser extensions may intercept keystrokes — try incognito mode or the desktop app.
   - Check if the shortcut was remapped in settings.
4. **In-app reference:** Click the **"?"** icon in the bottom-right corner, or press `Ctrl + /` for the live shortcut list.
